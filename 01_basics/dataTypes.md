# object types / data types

- Numbers: 1234, 3.143, 3+4j, 0b11, Decimal()
- String: 'span', "bob's"
- List: [1, [2, 'three'], 4, 5], list(range(10) )
- Tuple: (1, 'spam', 4, 'u'), tuple('spaam'), namedtuple 
- Dictionary: {'food': 'spam', 'taste': 'yum' dict(hours = 60)

- set: set('abc'), {'a, b, c}

- File: open('eggs.txt'), open(r'C: \ham.bin','wb')

- Boolean : true, false
- None: None
- Functions, modules, classes
